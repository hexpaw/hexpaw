## About

I'm based in [Seattle, Washington](https://en.wikipedia.org/wiki/Seattle), and my
professional work revolves around data obfuscation —
[masking](https://en.wikipedia.org/wiki/Data_masking),
[tokenization](https://en.wikipedia.org/wiki/Tokenization_%28data_security%29), and
[pseudonymization](https://en.wikipedia.org/wiki/Pseudonymization) — so that
sensitive records can pass through systems that have no business being able to
read them. The [NIST de-identification
guidance](https://csrc.nist.gov/pubs/ir/8053/final) is the reference I keep
coming back to, and the interesting problems are nearly always about keeping the
data useful after it's been depersonalized.

Most of that work lands in [Java](https://dev.java/) and
[Python](https://www.python.org/), with [SQL](https://en.wikipedia.org/wiki/SQL)
underneath most of it, and [PowerShell](https://learn.microsoft.com/powershell/)
doing the plumbing across Windows estates. I still think
[BASIC](https://en.wikipedia.org/wiki/BASIC) taught me more about how computers
actually work than anything I've learned since.
